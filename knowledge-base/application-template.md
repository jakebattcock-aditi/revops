# Application Template

Based on the Maker School method: lead with something built for THEM, make it obvious you read the post, keep it short. The client sees roughly the first 150 characters in the list, so those carry everything.

## First line (pick one, ~150 characters max)

- `Hi [name]. Mapped your [HubSpot → Salesforce] data flow before applying and found [3] places it will break. 2-min walkthrough (free): [link]`
- `Hi [name]. Audited the setup you described and drafted a fix list before applying. Free 2-min video: [link]`
- `Hi [name]. Built a working version of [the sync you described] before applying, free here: [link]`

Never open with "I am an expert / the best fit".

## Body (under 100 words)

```
[First line]

I run RevOps for a global B2B software company and recently [lead case study for this job type, from case-studies.md].

I'm new to Upwork, so I'm building my track record here with clients I can really help. Happy to start with a short call about [their specific problem].
```

## The giveaway (15 minutes, keep it simple)

Pick the one that fits the job:

- **CRM audit / cleanup:** a one-page "what I'd check first" list with 5–7 findings based on their post, in a Google Doc.
- **Integration / automation:** a flowchart of their data flow (Excalidraw or a screenshot of an n8n/Zapier canvas). It does not need to run.
- **Forecasting / reporting:** a sketch of the dashboard fields and where each comes from.

Looks hand-made and a bit rough, not polished. Too polished reads as AI-generated.

## Loom outline (2–3 minutes, one take, don't re-record)

1. Show the job post. Say 2 specific things about it.
2. One sentence about you and one case study, almost as an afterthought.
3. Show the giveaway and walk through exactly what you'd do.
4. Close: "If you'd like to chat, send me a few times that work. I'd like this to turn into a longer relationship."

## Connects rules (broke mode)

- Apply in the **first hour** a job is posted. That's when it's cheapest and you're most visible.
- **Don't boost** until you have a first review, unless a job is an exact match with a verified client. Boost small if you do.
- Skip jobs with **50+ proposals** that are more than a day old.
- Skip clients with **unverified payment**.
- Quality over volume: 2–3 tailored applications a day beats 10 weak ones when each costs real money.
