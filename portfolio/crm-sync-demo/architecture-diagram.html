Deal Sync: Source CRM to Target CRM

Six chained stages. Each one looks first, then updates or creates, so nothing is blindly copied. Demo built on made-up data.
Source CRM (new deal created)
Target CRM (records appear, linked and de-duplicated)
1Trigger
  • New deal arrives from the Source CRM
  • Wait 5 minutes so the related account and contacts finish saving
  • Pass IDs forward, stage to stage
2Account
  • Clean the name: 40-character limit, quote-safe
  • Region from sales org, currency as the fallback
  • Size band from employee count
  • Find in Target CRM, update or create
Blank beats wrong: no size data means no band, not a made-up one
3Contact
  • Deal role, then account primary, then first contact
  • Match by email, create if missing
No email? Log it and stop. A blank search can match the wrong person
4Partner
  • Secondary contact, else primary, else none
  • Empty is sent as null, never as blank text
5Campaign
  • Skip blank or "NO CAMPAIGN"
  • Translate the type between the two systems
  • Add the contact as a member
Unknown type stays blank. No guessing
6Deal
  • New Business or Upsell, from deal history
  • Owner falls back to a default
  • Create the deal and contact roles
Duplicate guard: already synced means log it and stop
Error log Every skipped or failed record is written to a log sheet with the reason. Nothing disappears silently, and nobody finds out three weeks later.
Illustrative demo. Made-up records and placeholder systems. Built with generic steps, so the same pattern works in n8n, Zapier, Make or plain code.
